# Ride-Analytics-Data-Dashboard
A data analytics dashboard built using Python, Streamlit, and Looker Studio to analyze ride patterns, fare trends, and driver performance in the Namma Yatri dataset across multiple Indian cities.
Namma Yatri Ride Analytics Dashboard is a data-driven project designed to extract actionable insights from ride-sharing data using Python and visualization tools.

The dashboard provides a comprehensive overview of ride behavior across five Indian cities — including analysis of ride frequency, fare patterns, cancellation rates, and driver performance metrics.

🔍 Key Features:

Data preprocessing and cleaning using Pandas

Exploratory analysis and visualizations with Matplotlib and Seaborn

Interactive dashboard built with Streamlit

Advanced visual summaries using Looker Studio

Insights on peak booking times, fare variations, and driver ratings

⚙️ Tech Stack:
Python, Pandas, Matplotlib, Seaborn, Streamlit, Looker Studio

📊 Dataset: Namma Yatri rides dataset (10,000+ records across 5 cities)

📈 Outcome:
Helped identify city-level ride trends, optimize driver performance, and suggest data-backed fare strategy improvements.
